가맹점 제휴 후보

뉴스뿐 아니라 Google News, Naver 지역·쇼핑·블로그, YouTube 등 여러 외부 채널에서 후보를 발굴한 뒤 기업명 검증 단계를 거쳐 실제 기업/브랜드 후보만 남깁니다.

i
발굴 기준

Google News를 기본으로 Naver 지역·쇼핑·뉴스·블로그 검색과 선택적으로 YouTube 검색을 결합합니다. Naver/YouTube API Secret을 GitHub Actions에 등록하면 추가 채널이 자동 활성화됩니다. 언론사·콘텐츠 채널·금융사·통신사·결제사업자는 기업명 검증 단계에서 제외하며, 공개적으로 자체 결제시스템이 확인되는 후보는 가맹점 후보에서 제외합니다. 결제시스템 미확인은 미보유를 의미하지 않습니다.
